# Feature codec completion batch

The completion shortcut is to repair shared causes, not to bless a whole-world mismatch count. Static dispatch-arm coverage is not executable coverage: a nested provider key can reject an otherwise implemented feature; a selector can then silently discard that child.

## Contract

- Run real Rust parsers over the pinned pack, including inline configured features and placement modifiers. List unsupported features explicitly rather than equating an accepted `Unknown` with an implementation.
- Reject an unparsed required child instead of shrinking a selector, predicate, or modifier list. Preserve supported legacy input spellings when adding the 1.21.1 spelling.
- Read predicate offsets where the native codec supports them. Preserve nested RNG draw order in the integer providers used by newly reachable features.
- Use the existing data-driven native feature oracle and the same scene JSON on both sides. Test positive and rejected placement, blocked columns, offset-sensitive predicates and post-placement RNG, not merely parse success.

## Verification slices

1. Reproduce nested codec losses; repair block-column providers and retain every selector child. Guard malformed required children.
2. Compare upward/downward block columns and biased heights against the pinned Java implementation; fix only demonstrated shared semantic gaps.
3. Replay the preserved sculk capture with its own population order. Report parser-loss counts separately from cell parity; a global count can worsen when previously missing features start executing. Run the broad repository gate once after the batch, not after each edit.

End spike and bonus chest remain explicit configured-feature gaps. Fossil now has a separate [bounded placement contract](fossil-placement.md); the codec batch itself did not establish it. This batch does not establish structures, runtime delivery, all dimensions, or whole-game parity. No main merge or publication is implied.
