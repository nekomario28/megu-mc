# 16 — 空inputの炉のrecipe lookupを省く

## 等価性

`out` が読まれるのは `input.1 > 0` のときだけ。
`can_smelt` は `input.1 > 0 && out...`、精錬分岐は `can_smelt` を通る。
よって `input.1 == 0` で `out` を計算しないのは同一結果。
状態・産出・xp・乱数消費は不変。

## ゲート

31テスト（serial/parallel）、Fabric/NeoForge check。
全fixtureで後退がないことを測定してから採用する。

**測定の基準はHEAD。** 不採用候補の測定を基準にすると
無関係なfixtureまで振れて読めなくなる。slice 15で踏んだ失敗。
