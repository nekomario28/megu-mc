本記録は seed `4242`・Overworld chunk `(3,-2)` における 18 セルの `snowy` 残差解消と、
残るセル差分の原因帰属を記録する。seed `4242` は引き続き探索比較であり、
本記録の調査時点では `minecraft:mineshaft` が未実装であり、native 生成順も未回収だった。
後続実装後も元の生成履歴は未確定で、committed acceptance fixture には昇格していない。

[seed由来のnormal-mineshaft layout](mineshaft-layout-20261113.md) の記録時点では、本番dispatcherとpiece配置への接続はまだだった。その後の [Rust接続・fresh全volume比較](mineshaft-production-20261113.md) は本番経路を検証したが、元のA/Bとの全差分解消やこのchunkの受け入れとは区別する。

## 修正内容（`Cf::FreezeTop` / `snow_can_survive`）

既存の [worldgen.rs](../../../src/worldgen.rs) の `Gen::apply_snowy` による事後 surface 書き換えを廃止し、
native `edn`（`SnowAndFreezeFeature`）と `dnj`（`SnowyDirtBlock`）および `ddw.b`（`Biome.shouldSnow` / `shouldFreeze`）に対応する
[feature.rs](../../../src/feature.rs) の `Cf::FreezeTop` / `snow_can_survive` と
[generation_context.rs](../../../src/generation_context.rs) の `FC::heightmap_uncached` を実装した:

1. 列ごとに `HeightmapKind::MotionBlocking` を参照する（従来の `WorldSurface` 回避ではない）。
2. `below = top - 1` に対して `cold_enough_to_snow`（`Weather::cold`）・`block_light < 10`・`water` source 判定を行い `ice` を配置。
3. `top` に対して `(is_air || snow) && snow_can_survive(below)` と同じ温度・光条件で `snow` を配置し、`below` が `snowy` property を持つ場合にのみ `snowy=true` を設定する（植物が上にある草ブロックを雪化しない）。
4. 独立オラクル [FreezeTopLayerOracle.java](../../../tools/structure-oracle/FreezeTopLayerOracle.java)（29 場面）を公式 jar で実行し [freeze_top_layer_1211.tsv](../../../tests/data/freeze_top_layer_1211.tsv) を採取、[generation_contract_tests.rs](../../../src/generation_contract_tests.rs) に `freeze_top_layer_matches_native_oracle` と [mutation_check.sh](../../../tools/mutation_check.sh) に 4 件の compiling mutant を追加した（pre-change 失敗は `cold_grass_air` で確認、post-change は 29/29 場面通過・4/4 mutant proved）。
