## 1. The two code changes

`src/worldgen.rs`, in `Gen::populate_in_order` (pre-edit line 8782, post-edit 8786-8792):

```diff
-        let gate = jobs > 1 && self.pop_region.is_none() && is_feature_driver;
+        let gate = jobs > 1
+            && self.starts_round.is_some()
+            && self.pop_region.is_none()
+            && is_feature_driver;
```

A3-a scratch generators copy `owner.starts_round` (`src/feature.rs:9812,9836,9380`). With
`terrain_jobs()` = 8 (default) but `delivery_prefetch_jobs()` = 1 (default), no round is opened
on delivery (`src/main.rs:21712-21716`), so each worker rebuilt structure starts / terrain
answers on a thread-local cache — the 57–63 s thrash E4-12 §5 attributed to this asymmetry.
The gate now requires a shared round.

`src/worldgen.rs`, `biome_name_at_block` (pre-edit 10634, post-edit 10644):

```diff
 /// Block-space biome name through the same quart lookup as the feature layer.
+#[cfg(test)]

```

Docstring and body preserved; the only caller is `#[cfg(test)]` (§0.1).

**Why batch worldgen is unaffected.** `tools/perf_bench.py:434` sets `MC_SPINE_GEN_JOBS=jobs`;
`gen_workers()` = `worldgen::terrain_jobs()` (`src/main.rs:21557-21559`), and the dump path opens
`dump_round = (dump_workers > 1).then(starts_round_begin)` and sets
`g.starts_round = Some(round)` (`src/main.rs:32966-32974`). Therefore `--jobs 5/8` still passes
the new gate and still dispatches A3-a in parallel — verified by the wall times in §4 (j5/j8
remain faster than j1) and by all nine digests matching.

## 6. Residual finding and next safe action (honest boundary)

Option (a) is a **correct, minimal fix for the P0 asymmetry** but is not sufficient by itself to
reach the ~7–9 s target. The A/B in §3 isolates the residual: with A3-a already serialized in
both rows, `MC_SPINE_GEN_JOBS=1` (which also sets `terrain_jobs()=1`) gives 8.211 s while the
default (`terrain_jobs()`=8) gives ~14.5 s. The ~6.3 s delta is the parallel carver stage:
`carve_ring` calls `carve_ring_with(g, sx, sz, crate::worldgen::terrain_jobs())`
(`src/feature.rs:9277-9279`) unconditionally, so with no shared round open each of the 81
chunks' carver passes spawns 8 workers on thread-local caches. `src/feature.rs` is outside this
lane's strict file ownership, so it was **not** edited.

- **Proven by this lane:** the P0 A3-a round-gate fix; warning removal; valid `WARM=1` `LoadA`;
  unchanged determinism digests; unchanged batch parallelism; all static/targeted gates green.
- **Not proven:** that option (a) alone yields ~7–9 s cold initial latency. Measured 14.42–17.68 s.
- **next_safe_action:** a follow-up lane owning `src/feature.rs` should make `carve_ring`'s worker
  count respect the same shared-round precondition (or pass 1 when no round is open) and
  re-measure the cold first-`0x0C` clock against the 8.211 s `GEN_JOBS=1` A/B, then re-run §4/§5
  gates. Do not relax any deadline or digest to absorb this cost.
