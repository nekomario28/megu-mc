How it stays lightweight

Your own server.jar

No Mojang binaries or assets are ever shipped. Runtime tables are generated locally from your own official Minecraft jar on first setup.

Drop-in modpacks

36 performance mods (Sodium, Lithium, ModernFix, Distant Horizons, and more) are skipped automatically. Create kinetics, Farmer's Delight & addons, and OpenPAC/FTB Chunks have clean-room Rust engines; unsupported Mixins delegate safely to NeoForge.

Built for every GPU

Selectable client rendering path: Vulkan Mesh Shaders (RTX, Radeon RDNA2+, Arc), Compute + Multi-Draw Indirect, and a low-VRAM UBO path designed for older Intel HD/UHD integrated graphics.

Clean-room open source

Written from scratch in Rust with zero external crates in the core workspace. Root licensed GPL-3.0-or-later; first-party crates triple-licensed LGPL/GPL/AGPL-3.0-or-later.

Three commands to launch.

1. Initialize a server directory
mc-spine-init init --dir ./server --mc-version 1.21.1
2. Inspect a modpack or mods/ folder (no JVM needed)
mc-spine-mod-check --scan-mods-dir ./server/mods
3. Accept eula.txt and start
cd ./server && mc-spine
Docker, world migration (1.21.1 ↔ 26.3), server ping, voice relay & source build 
# Docker (requires explicit EULA=TRUE)
docker build -f docker/Dockerfile -t mc-spine:alpha .
docker run --name mc-spine -e EULA=TRUE -p 25565:25565 -v mc-spine-data:/data mc-spine:alpha

# Inspect or migrate a Vanilla world between 1.21.1 and 26.3
mc-spine-world-migrate inspect-anvil ./world
mc-spine-world-migrate migrate-level --in ./world/level.dat --out ./world/level.dat --to 26.3 --backup-old

# Probe a running server (SRV-aware, 1.21.1 or 26.3)
mc-spine-client --ping localhost:25565

# Run the standalone UDP proximity voice relay self-test
mc-spine-voice-relay --self-test

# Build from source (Rust 1.98.0)
cargo run --locked

Current status

Available in Alpha

  • Vanilla 1.21.1 protocol, online-mode AES-CFB8 auth, and Velocity modern forwarding
  • Deterministic worldgen, random ticks, villagers, commands, ops/bans/whitelist, RCON, and async backups
  • Standalone CLI suite: server bootstrapper & OpenPAC claims, zero-JVM mod/Mixin scanner, Anvil & 26.3 migrator, SRV client ping, and UDP voice relay

Still in progress

  • Full vanilla parity across combat, remaining gamerules, and general-seed worldgen
  • Native Anvil live world storage and broader live modpack execution
  • Standalone GPU client rendering (Bukkit/Spigot/Paper plugins are out of scope — use Velocity plugins or NeoForge/Fabric mods)
