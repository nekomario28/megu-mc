Quickstart

Three commands to a running server

Release binaries ship the whole toolchain. Scaffold a server directory, pre-flight a modpack, launch.

1 · Scaffold

mc-spine-init init --dir ./server --mc-version 1.21.1

2 · Pre-flight a modpack

mc-spine-mod-check --modpack ./packs/my-pack.mrpack --mc-version 1.21.1

3 · Run

cd ./server && mc-spine
More commands — world migration, client ping, dev build 
# Migrate a saved world to the latest target
mc-spine-world-migrate migrate --in world.stv1 --out world-26_3.stv1 --to 26.3

# Ping a running server (SRV-aware)
mc-spine-client --ping localhost:25565

# From a source checkout (Rust 1.98.0, pinned via rust-toolchain.toml)
cargo run --locked

Docker

docker build -f docker/Dockerfile -t mc-spine:alpha .
docker run --name mc-spine -e EULA=TRUE -p 25565:25565 \
    -v mc-spine-data:/data mc-spine:alpha

The image ships no Mojang data and refuses to start without EULA=TRUE. Optional MC_SPINE_MODPACK runs the same pre-flight the checker above demonstrates.

Architecture

4-tier mod execution

Every mod JAR and datapack is classified before launch. Redundant performance mods are recognized up front and skipped so their Mixins can never force a JVM fallback.

TierNameHow it runs
Tier 0 Native Flagship Dedicated Rust adapter — zero JVM. Ships with a create adapter; more flagships planned.
Tier 1 Universal Native Pure-data or declarative offload profile — datapacks, resourcepacks, configs, profiled mods. Zero JVM.
Tier 2 Bounded JVM Shim ShimCheck-verified NeoForge/Fabric bytecode inside a bounded S0–S4 sandbox with direct batch + offload.
Tier 3 Quarantine / NeoForge Fallback Unsupported Mixin/AT or unknown net.minecraft.* surface — quarantined under a Save v2 integrity guard, or delegated to the pinned upstream NeoForge runtime.
Auto-skipped Built-in optimizations sodium, lithium, modernfix, distanthorizons and 32 more perf mods whose optimization surface mc-spine already implements natively — recognized before ShimCheck and skipped automatically.

What works / what's experimental — honestly

StatusAreaNotes
Verified Worldgen & protocol parity Fixed-seed / chunk / stage oracle comparisons against vanilla 1.21.1, plus the 26.3 wire target.
Verified Modpack pre-flight Modrinth .mrpack + CurseForge manifest.json analysis — the same code the checker above runs.
Verified Velocity forwarding Modern forwarding supported; run mc-spine behind a Velocity proxy.
Experimental Mod compatibility Tier 0 flagship create, Tier 1 profiles and the Tier 2 bounded shim are alpha; arbitrary mods are not guaranteed.
Experimental M2/M3 full parity Full session parity (rendering, complete client loop) is still in progress — this is an alpha runtime.
Not this Bukkit/Paper plugins mc-spine is not a plugin server like Mohist — no Bukkit API. Mods go through the 4-tier pipeline instead.
