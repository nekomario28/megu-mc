1. Official Launcher & Native wgpu Client

megu-installer needs no Java. GUI (double-click or megu-installer gui) and CLI modes register the Megu (1.21.1) profile in the Official Launcher and stage megu-client-gpu, the native client. Windows requires Windows 10/11; macOS requires macOS 11 or later.

Zero manual steps: megu-client-gpu is pure wgpu (Vulkan / DX12 / Metal) with zero OpenGL and zero JVM. On first launch it reuses an existing Vanilla 1.21.1 install when present, otherwise downloads the client JAR from Mojang's official HTTPS hosts, verifies SHA-1, and starts.

Megu Dedicated Server (megu)

Provision a server with megu-installer, accept eula.txt, and launch. Online-mode AES-CFB8 auth, Velocity Modern Forwarding, RCON, Docker, and systemd are supported without a JVM.

01Create server directory
./megu-installer server --dir ./megu-server
02Accept eula.txt and launch
cd ./megu-server && ./megu --port 25565
Verify a pinned Linux archive before installing (SHA-256)

Release tag: v0.1.0-alpha.5. Download SHA256SUMS-all.txt, extract your target archive into SHA256SUMS.txt, and verify with sha256sum -c before extracting. 

TAG=v0.1.0-alpha.5
TARGET=linux-x86_64
ARCHIVE="megu-${TAG}-${TARGET}.tar.gz"
BASE="https://github.com/nekomario28/megu-mc/releases/download/${TAG}"
curl -fLO "${BASE}/${ARCHIVE}"
curl -fLO "${BASE}/SHA256SUMS-all.txt"
grep -F "  ${ARCHIVE}" SHA256SUMS-all.txt > SHA256SUMS.txt
test "$(wc -l < SHA256SUMS.txt)" -eq 1
sha256sum -c SHA256SUMS.txt
tar -xzf "${ARCHIVE}"
"./megu-${TAG}-${TARGET}/megu-installer" server --dir ./megu-server
