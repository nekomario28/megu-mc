Quickstart

1. Initialize a server directory
mc-spine-init init --dir ./server --mc-version 1.21.1
2. Check a modpack before launch
mc-spine-mod-check --modpack ./my-pack.mrpack --mc-version 1.21.1
3. Accept eula.txt and start
cd ./server && mc-spine
Docker, world migration, server ping & source build 
# Docker (requires explicit EULA=TRUE)
docker build -f docker/Dockerfile -t mc-spine:alpha .
docker run --name mc-spine -e EULA=TRUE -p 25565:25565 -v mc-spine-data:/data mc-spine:alpha

# Inspect or migrate a world between 1.21.1 and 26.3
mc-spine-world-migrate inspect-anvil ./world
mc-spine-world-migrate migrate-level --in ./world/level.dat --out ./world/level.dat --to 26.3 --backup-old

# Probe a running server (SRV-aware, 1.21.1 or 26.3)
mc-spine-client --ping localhost:25565

# Build from source (Rust 1.98.0)
cargo run --locked

Compatibility & current scope

Mod execution

Auto-skipped performance mods
Recognizes 36 common client/server optimization mods (such as Sodium, Lithium, ModernFix, Distant Horizons) and skips loading them because equivalent behavior is built in natively.
Native & data-driven mods
Datapacks, resource packs, Create kinetics/contraptions, Farmer's Delight & culinary addons, and OpenPAC/FTB Chunks claims run in Rust without a JVM.
Standard Java mods & fallback
Standard NeoForge/Fabric mods run via a bounded bridge; heavy Mixin mods either stay quarantined or delegate safely to upstream NeoForge.

Server & client status

Working today
Vanilla 1.21.1 protocol, worldgen parity, online-mode auth, Velocity modern forwarding, RCON, ops/bans/whitelist, autosave & backups, and 26.3 wire/migration tooling.
In progress
Full vanilla combat/gamerule parity, native Anvil live storage, standalone GPU client rendering, and broader live mod coverage.
Out of scope
Bukkit/Spigot/Paper plugins (use Velocity proxy plugins or NeoForge/Fabric mods instead).
